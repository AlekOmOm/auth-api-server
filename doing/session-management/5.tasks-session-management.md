**Task 0.4: Enhance Existing Session Handling** [ ]
- **Objective:** Work with existing session tables in each schema, add Redis caching layer
- **Action(s):**
  1. **Keep existing session tables**: No changes to current `sessions` table in each client schema
  2. Create `backend/src/services/session/redis-cache.service.js`:
     ```javascript
     // Redis keys: sess:{schema_name}:{session_id}
     // This maintains existing tenant isolation pattern
     class SessionCacheService {
       getSessionKey(schema, sessionId) {
         return `${process.env.REDIS_SESSION_PREFIX}${schema}:${sessionId}`;
       }
       
       async cacheSession(schema, session) {
         const key = this.getSessionKey(schema, session.sessionId);
         await redis.setex(key, 24 * 60 * 60, JSON.stringify(session));
       }
       
       async getCachedSession(schema, sessionId) {
         const key = this.getSessionKey(schema, sessionId);
         const cached = await redis.get(key);
         return cached ? JSON.parse(cached) : null;
       }
     }
     ```
  3. Verify existing session table structure remains unchanged
- **Verification/Deliverable(s):** Redis caching layer added, existing database schema preserved

  2. Create `backend/src/services/session/hybrid-session.service.js`:
     ```javascript
     // Orchestrates between Redis cache and existing PostgreSQL sessions
     class HybridSessionService {
       async createSession(userId, schema, ipAddress, userAgent) {
         // Use existing Session.forLogin factory
         const session = Session.forLogin(userId, ipAddress, userAgent);
         
         // Save to existing PostgreSQL (audit trail)
         const savedSession = await sessionRepo.createSession(schema, session);
         
         // Cache in Redis (performance)
         await savedSession.cacheInRedis(schema);
         
         return savedSession;
       }
       
       async validateSession(sessionId, schema) {
         // Fast Redis lookup first
         let session = await Session.fromCache(schema, sessionId);
         
         // Fallback to existing DB validation
         if (!session) {
           session = await sessionRepo.getBySessionId(schema, sessionId);
           if (session) await session.cacheInRedis(schema);
         }
         
         return session && !session.isExpired() ? session : null;
       }
     }
     ```
  3. Keep all existing session validation logic
